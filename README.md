# Excel-помощник (бесплатный AI агент на Gemini)

Веб-приложение: пишешь задачу по Excel, при желании прикладываешь файл — агент (Google Gemini) возвращает готовый файл и краткое объяснение. **API бесплатный**.

Под капотом:
- LLM — **Google Gemini 2.5 Flash** через [Google AI Studio](https://aistudio.google.com) (бесплатный тариф, ~1500 запросов в сутки).
- Превью файла (имена листов, столбцы, первые строки) отправляется в Gemini.
- Gemini возвращает Python-код в JSON.
- Код **запускается локально** на твоём компьютере с pandas/openpyxl над полным файлом.
- Готовый `.xlsx` отдаётся ссылкой на скачивание.

> ⚠️ **Важно про безопасность.** Приложение исполняет Python-код, сгенерированный моделью, у тебя на машине. Запускай его только локально с собственными файлами; не публикуй его в интернет.

## Получить бесплатный ключ

1. Открой https://aistudio.google.com/apikey (нужен Google-аккаунт).
2. Нажми **«Create API key»** → выбери проект (или создай новый).
3. Скопируй ключ — он начинается на `AIza...`.
4. Лимиты бесплатного тарифа (на момент написания):
   - **Gemini 2.5 Flash** — 15 запросов в минуту, 1500 в сутки.
   - Этого с большим запасом хватит на личное использование.

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/farizpro111-source/claudeai.git
cd claudeai

# 2. Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1

# 3. Зависимости
pip install -r requirements.txt

# 4. Ключ
cp .env.example .env                # Windows: copy .env.example .env
#   открой .env и впиши GEMINI_API_KEY=AIza...
```

## Запуск

```bash
python app.py
```

Открыть http://localhost:8000

## Как пользоваться

1. Опиши задачу — например: «сделай сводную по столбцу 'Регион' с суммой 'Выручка'».
2. По желанию: кнопка **«+ Файл»** → выбери `.xlsx` / `.xls` / `.csv`.
3. **Enter** или «Отправить».
4. Получишь короткое объяснение + ссылку **⬇ result.xlsx** — кликай и скачивай готовый файл.
5. Можно продолжать в том же диалоге («теперь добавь столбец процент») — контекст сохраняется до кнопки «Новый диалог».

## Что умеет

- Свод, фильтры, сортировка, чистка данных, удаление дубликатов, объединение листов.
- Формулы / макросы текстом, если файл не нужен.
- Анализ структуры файла («что в нём?» + рекомендации).

## Файлы

- `app.py` — FastAPI: `/` (UI), `/chat`, `/download/{session_id}/{filename}`, `/reset`.
- `templates/index.html`, `static/` — простой чат-интерфейс.
- Рабочие папки сессий — `/tmp/excel_app_sessions/<session_id>/`. Кнопка «Новый диалог» удаляет их.

## Частые проблемы

| Проблема | Что делать |
|---|---|
| `GEMINI_API_KEY не задан` | проверь `.env`, без кавычек, без пробелов |
| `ModuleNotFoundError` | окружение не активировано — `source .venv/bin/activate` |
| Порт 8000 занят | `uvicorn app:app --port 8080` |
| «Ошибка выполнения» в ответе | модель сгенерировала плохой код. Уточни задачу и попроси ещё раз |
| 429 / превышен лимит | подожди минуту или до следующего дня |
