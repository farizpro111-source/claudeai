# Kaspi PDF → Анализ расходов

Простое локальное веб-приложение: загружаешь PDF выписку из Kaspi Bank — получаешь
разбивку по категориям с возможностью править каждую транзакцию и оставлять
примечания. Всё работает у тебя на машине, банковские данные никуда не уходят.

## Что умеет

- Парсит официальный PDF выписку Kaspi (даты, суммы, типы операций, описания).
- Автоматически раскладывает покупки по категориям по ключевым словам
  (Magnum → Продукты, KFC → Кафе, Yandex Go → Транспорт, и т.д.).
- Все «Переводы» без комментариев попадают в `Перевод (входящий/исходящий)` —
  потом можно вручную переложить их в «Долги», «Не моё» или любую другую категорию.
- К каждой транзакции можно добавить **примечание** (например: «вернул долг Айдару»,
  «оплатил за маму»).
- Можно **запомнить правило**: один раз отметив «перевод Айгерим = долг», все
  будущие такие переводы при следующих загрузках попадут туда автоматически.
- Сводка по категориям, фильтры по дате/категории/поиску, общий приход/расход.
- Никаких облаков, никакой регистрации — SQLite на диске + Flask.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000, нажмите «Выбрать файл» в шапке и загрузите PDF
выписки из Kaspi (в приложении: `Главная → ваш счёт → ⋮ → Выписка → PDF`).

## Структура

```
app.py            # Flask, маршруты, склейка всего
parser.py         # извлечение транзакций из PDF
categories.py     # список категорий и правила автокатегоризации
db.py             # SQLite-хранилище
templates/        # HTML
static/style.css  # стили
data/kaspi.db     # БД с транзакциями (создаётся при первом запуске)
```

## Как добавить свои категории / правила

Откройте `categories.py`:

- `CATEGORIES` — список доступных категорий. Просто допишите свою строку.
- `RULES` — список `(категория, [подстроки])`. Добавьте сюда новые ключевые слова,
  и при следующей загрузке транзакции с такими словами в описании сразу попадут
  в нужную категорию.

Альтернатива: правьте категорию прямо в веб-интерфейсе и ставьте галочку
«запомнить правило для подстроки» — приложение само сохранит правило в БД.

## Если PDF разбирается криво

Kaspi периодически меняет формат выписки. Парсер устойчив к большинству вариантов,
но если что-то идёт не так — поправьте регулярки `DATE_RE`, `AMOUNT_RE` и список
`TYPE_KEYWORDS` в `parser.py`. Весь остальной код от формата PDF не зависит.
