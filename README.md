# Excel-помощник (AI агент)

Веб-приложение: пишешь задачу по Excel, при желании прикладываешь файл — агент возвращает готовый файл и краткое объяснение.

Под капотом — Anthropic Claude (`claude-opus-4-7`) + серверный инструмент **code execution** (pandas / openpyxl / xlsxwriter уже установлены в песочнице Anthropic) + **Files API** для загрузки исходников и скачивания результата.

## Что умеет

- Принимает `.xlsx`, `.xls`, `.csv`.
- Выполняет преобразования: сводные, фильтры, формулы, чистка данных, объединение листов, форматирование.
- Возвращает готовый `.xlsx` со ссылкой на скачивание.
- Помнит контекст в рамках сессии (контейнер переиспользуется между сообщениями — можно итеративно править файл).
- Если файла нет, отвечает текстом: формулы, советы, шаги.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# впишите свой ANTHROPIC_API_KEY в .env
```

## Запуск

```bash
python app.py
# или
uvicorn app:app --reload
```

Открыть http://localhost:8000

## Структура

- `app.py` — FastAPI: `/` (UI), `/chat` (одно сообщение + опц. файл), `/download/{file_id}`, `/reset`.
- `templates/index.html`, `static/` — простой чат-интерфейс на русском.
- Состояние сессии (`container_id`, история сообщений) — в памяти процесса. Для прода вынести в Redis/БД.

## Замечания

- Один контейнер живёт до 30 дней — все загруженные файлы и созданные внутри файлы доступны для последующих ходов в той же сессии.
- Кнопка «Новый диалог» сбрасывает сессию и контейнер.
- API-ключ читается из переменной окружения `ANTHROPIC_API_KEY`.
