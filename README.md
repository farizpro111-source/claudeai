# Kaspi Анализ расходов

Простое локальное веб-приложение: загружаешь PDF-выписку из Kaspi.kz —
получаешь разбивку расходов и доходов по категориям, с возможностью
**вручную править категории и добавлять примечания** к каждой операции
(удобно для переводов без комментариев, долгов, «не моих» трат и т.д.).

Всё работает локально, никакие данные никуда не уходят. Хранилище —
обычный файл `kaspi.db` (SQLite) рядом с `app.py`.

## Что умеет

- Парсит PDF-выписку Kaspi (Главная → История → ⋯ → Выписка → PDF).
- Автоматически раскидывает операции по категориям по списку магазинов /
  ключевых слов (Magnum, Yandex Go, KFC, Kaspi Shop, аптеки, АЗС, связь,
  переводы, снятие наличных и т.п.).
- Веб-интерфейс со сводкой по категориям, фильтрами и поиском.
- На каждой строке можно:
  - сменить категорию из выпадающего списка (включая «Долги», «Не мои
    траты», «Подарки», «Семья» — то, что нельзя угадать автоматически);
  - вписать **примечание** (например, «долг Айдару» — потом найдёшь
    поиском или фильтром).
  - удалить строку, если она лишняя.
- Изменения сохраняются автоматически (категория — сразу, примечание —
  через ~0.5 сек после ввода).
- Импорт идемпотентный: одну и ту же выписку можно загружать повторно —
  дубликаты не появятся, а сделанные тобой правки сохранятся.
- Экспорт всего в CSV (для Excel / Google Sheets).

## Запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python app.py
```

Открой <http://127.0.0.1:5000> в браузере и загрузи PDF.

## Структура

| Файл                  | Назначение                                        |
|-----------------------|---------------------------------------------------|
| `app.py`              | Flask-приложение, маршруты, БД                    |
| `parser.py`           | Извлечение транзакций из Kaspi PDF (pdfplumber)   |
| `categorizer.py`      | Правила авто-категоризации                        |
| `templates/index.html`| UI                                                |
| `static/style.css`    | Стили                                             |
| `kaspi.db`            | SQLite (создаётся автоматически, в git не уходит) |

## Как добавить свою категорию или магазин

Открой `categorizer.py` и допиши ключевые слова в нужную категорию в
`CATEGORY_RULES` (или добавь новую категорию — она сама появится в
дропдауне). Перезапускать приложение не обязательно, если используется
`debug=True` — Flask подхватит изменения.

## Замечания по парсингу

Kaspi периодически меняет вёрстку PDF-выписок. Парсер написан
устойчиво (ищет строки с датой + суммой), но если какие-то операции не
импортировались — проверь, что в PDF дата стоит в формате `DD.MM.YYYY`
(это формат «официальной выписки», а не «истории операций» как картинка).
Если что-то не подцепилось — можно открыть `app.py` и временно
включить `print(raw)` в `/upload`, чтобы посмотреть распознанные строки.
